# 冷启动运营方案（0 到 1000 粉阶段）

核心事实：公众号没有自然流量池，0 粉阶段阅读量 100% 来自主动分发。冷启动 = 好内容 + 好门面 + 系统化分发。

## 更新节奏

- 每周 1 篇，固定周四或周日晚 21:00。宁可少发，不断更。
- 系列化是最重要的策略：编号 + 固定封面版式 + 文末预告下一篇。

## 每篇发布后分发清单（必做）

1. 朋友圈：50 字以内个人化推荐语，不裸转链接。
2. 微信群：实验室群、年级群、校友群、考研群，每次 2 到 3 个最相关的群，附一句「第 X 篇，讲 XX，需要的自取」。
3. 知乎：找高关注相关问题，把文章改写成回答，文末挂公众号。新号最重要的外部流量源。
4. 小红书 / 即刻 / B 站动态：把正文里的图单独发，图本身就是传播物料。
5. 文章末尾固定一句转发钩子。

## 互动与留存

- 被关注自动回复：账号价值一句话 + 系列目录 + 关键词指引。
- 关键词回复：「生存栈」返回系列目录，「工具」返回工具清单；后续放资料包，用资料换关注。
- 每篇结尾留 1 个具体留言问题，留言必回。
- 攒够 3 篇设置自定义菜单：系列目录｜工具箱｜关于。

## 每周看一次的数据指标

| 指标 | 冷启动期参考值 | 说明 |
|---|---|---|
| 阅读完成率 | ≥ 40% | 低于 30% 说明太长或开头太拖 |
| 分享人数 / 阅读量 | ≥ 8% | 新号最重要指标，比阅读量重要 |
| 单篇净增关注 | ≥ 20 | 哪篇涨粉多就沿哪个方向写 |
| 留言数 | ≥ 3 | 检验互动钩子 |

新号前 2 个月阅读量两位数很正常，盯分享率和净增关注，别盯阅读量绝对值。

## 选题来源

- 主干系列按 Research Stack 分层逐层写（00 总览已发，01 超级搜索已发，02 Git 待写）。
- 留言区问题是最准的选题库。
- 蹭热点只蹭与「研究生 + AI 工具」直接相关的，不硬蹭。
