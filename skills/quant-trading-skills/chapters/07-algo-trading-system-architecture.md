# 07 - 算法交易系统架构与实盘工程体系

> 本模块解构欧内斯特·陈 (Ernest P. Chan) 经典著作《量化交易：如何建立自己的算法交易事业》的核心框架，阐述工业级量化交易系统的四大支柱、真实性检验标准与回测防伪军规。

---

## 1. 算法交易系统的四大工程支柱

一个能持续盈利且经得起市场风浪的算法交易系统，由四个完全解耦又高度闭环的子系统构成：

```
┌────────────────────────────────────────────────────────┐
│ 1. 策略识别与构思 (Strategy Identification)           │
│    · 寻找经济学微观结构支撑的 Alpha                   │
└──────────────────────────┬─────────────────────────────┘
                           │ 验证可行性
                           ▼
┌────────────────────────────────────────────────────────┐
│ 2. 严谨回测验证引擎 (Backtesting Engine)              │
│    · 零偏差数据清洗、保守撮合假设、过拟合审计          │
└──────────────────────────┬─────────────────────────────┘
                           │ 达到准入指标
                           ▼
┌────────────────────────────────────────────────────────┐
│ 3. 执行系统与低时延路由 (Execution System)             │
│    · 算法订单拆单 (TWAP/VWAP)、滑点对抗、连接经纪商 API │
└──────────────────────────┬─────────────────────────────┘
                           │ 风险约束闭环
                           ▼
┌────────────────────────────────────────────────────────┐
│ 4. 资金与动态风险管理 (Money & Risk Management)         │
│    · 凯利仓位配比、最大回撤截断、黑天鹅熔断保护        │
└────────────────────────────────────────────────────────┘
```

## 2. 策略挖掘的三大可靠源泉与真伪甄别

盲目用计算机穷举技术指标组合绝不可能获得长青策略。Ernest Chan 强调策略必须根植于**结构性的市场非完美性**：

1. **结构性非经济理性交易者创造的获利机会**：
   - 指数基金季度成分股定期再平衡（如沪深300指数调整，数以千亿计的资金必须在确定日期按规则建仓/平仓，引发巨大的可预测被动冲击）；
   - 中央银行公开市场操作或汇率干预；
   - 具有法定投资限制的机构投资人（如险资必须抛售被降级为非投资级的垃圾债、公募基金临近清盘线的被动抛售）。
2. **微观流动性与摩擦补偿**：
   - 为流动性较差的深度期权或小盘股提供做市双边报价，赚取买卖价差（Bid-Ask Spread）；
   - 跨市场或跨品种的统计套利（如商品跨期基差套利、ETF 申赎溢价对冲）。
3. **学术文献的降维落地**：
   - 优先选择顶刊（*Journal of Finance*, *Journal of Financial Economics*, *Review of Financial Studies*）中经过数十位同行评审的经典异象；
   - **甄别陷阱**：凡是声称发现某种神奇神经网络或极其复杂的几十个技术指标复合公式的论文，99% 是样本内过拟合；越是朴素、机理透明的策略（如均值回归、供需周期），在实盘中越具有长久生命力。

## 3. 回测系统的四大致命陷阱与检验军规

### 3.1 陷阱一：向前看偏差 (Look-ahead Bias)
* **表现**：回测代码在计算 $T$ 日决策信号时，无意中引用了未来信息。
* **隐蔽形态**：
  - 使用了当天的收盘价 `Close[T]` 计算指标，却假设在当天以开盘价 `Open[T]` 或以 `Close[T]` 瞬间满仓成交；
  - 数据预处理时对全样本（包含未来 5 年数据）一次性做了 Z-Score 标准化（未来的均值和方差泄漏给了历史）；
  - 引用未正式公告的公司财报。
* **防伪军规**：严格遵守 **$T-1$ 日收盘后或 $T$ 日开盘前** 的严格只读权限；回测引擎每一跳（Tick/Bar）只能向前递推，严禁跨行切片。

---

### 3.2 陷阱二：幸存者偏差 (Survivorship Bias)
* **表现**：只在当前存活的股票池中回溯 10 年历史。
* **后果**：那些在过去 10 年中暴跌 90%、退市、破产清算的劣质公司被完全隐匿，留下的全是被市场选出的赢家，导致任何简单的买入持有策略都获得逆天收益。
* **防伪军规**：回测必须使用包含**已退市股票 (Delisted Stocks)** 的完整历史点对点数据库 (Point-in-Time Database)。

---

### 3.3 陷阱三：数据挖掘与过拟合 (Data Snooping)
* **表现**：通过尝试数百个均线周期参数、止损点百分比、过滤指标，挑选出净值曲线最完美的参数组合。
* **防伪军规**：
  - 核心参数不得超过 3 个；
  - 参数必须处于宽广的平缓收益高原（Parameter Plateau）之上，对细微变动不敏感；
  - 必须保留至少 30% 以上的未触碰全新样本进行最终的样本外锁定验证。

---

### 3.4 陷阱四：成交假设幻想 (Execution Fantasy)
* **表现**：假设无论何时挂限价单都能 100% 撮合成交，或者假设几十手大单能以盘口第一档最优价格瞬间扫光。
* **防伪军规**：
  - 保守滑点扣除：每笔交易强制扣除单边 $1 \sim 2$ 个最小变动价位（Tick）；
  - 成交量约束：单笔委托不得超过当根 K 线总成交量的 $2\% \sim 5\%$；
  - 涨跌停与停牌严格不可成交。

## 4. 实盘策略准入与评价量化基准

在策略正式注入真实真金白银之前，必须通过以下量化考核门槛：

| 指标 | 门槛要求 | 经济学含义 |
| :--- | :--- | :--- |
| **年化夏普比率 (Sharpe Ratio)** | **$> 1.5$** (日频)；**$> 2.5$** (高频) | $\frac{E[R - R_f]}{\sigma \sqrt{252}}$。衡量每承担一单位波动率所获得的超额补偿。低于 1.0 的策略在真实扣费和滑点后往往归零。 |
| **卡玛比率 (Calmar Ratio)** | **$> 2.0$** | 年化超额收益 / 历史最大回撤。直接衡量策略回撤痛苦指数与修复能力。 |
| **最大回撤持续期 (Drawdown Duration)** | **$< 6$ 个月** | 连续亏损无法创新高的最长跨度。过长的时间跨度会导致交易团队心理崩溃或资金方强行赎回。 |
| **盈亏比与胜率匹配** | 趋势型策略：胜率 35%~45%，盈亏比 $\ge 2.5$; <br>均值回归型：胜率 60%~75%，盈亏比 $\ge 0.8$ | 任何策略都不可能同时拥有 90% 胜率和超高盈亏比；脱离盈亏比谈胜率是业余投资者的标志。 |
