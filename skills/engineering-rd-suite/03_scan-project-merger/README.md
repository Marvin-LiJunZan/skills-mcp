# 扫描工程财税档案批量合并与智能重组技能 (Scan Project Merger Skill)

> **为工程科研课题、横向课题、高企加计扣除专项打造的扫描件批量处理工作流。**

---

## 🎯 解决的核心痛点

1. **扫描方向倒错混乱**：
   原始扫描件来自进纸式高速扫描仪或手机扫描，表格经常横倒、倒置（90°/270°），本技能提供基于页面长宽比和文字布局的自动化正向纠偏（自动旋转为 Landscape A4 841.7 × 595.2 pt）。
2. **多年度与多年份跨期文件混杂**：
   从单份长篇扫描件（如 `scan_20261016134436.pdf`）中按课题合同编号、年份自动切分并重组出独立的年度汇总表与明细分卷。
3. **多部门独立核算隔离**：
   长距离课题中同时存在“总部科研人员”与“现场总承包部人员”时，自动分离为独立的 PDF 子卷，防止审计交叉混拼。
4. **规范化三分法归档体系**：
   - `scan原件/`：高保真归档原始扫描件（留存备查，不破坏印章与签字）。
   - `md件/`：生成结构化 Markdown 档案（包含项目全称、合同编号、区间、人员及审计勾稽要点）。
   - `合并好的pdf/`：输出标准命名（`研发人员及设备、无形资产的分配+<项目简称>.pdf`）的正向终稿。
