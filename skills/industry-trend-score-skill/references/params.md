# 可调参数

以下参数可在 `config/strategy.json` 中修改，或用自然语言让 Codex 修改。

## 可调整的策略参数

- 短期均线天数（ma_fast）：当前值 30，范围 5~120 天；含义：把最近多少个交易日净值取平均，用来观察行业近期平均走势。
- 长期均线天数（ma_slow）：当前值 250，范围 60~500 天，且必须大于短期均线；含义：把最近多少个交易日净值取平均，用来观察行业中长期平均走势。
- 持有行业数（top_k）：当前值 2，范围 1~5 个；含义：每月最多选择几个行业持有。
- 行业资金分配方式（weight_scheme）：当前值 风险平价，范围 等权/排名加权/评分加权/风险平价；含义：决定选中的行业各分配多少资金；风险平价会降低高波动行业的资金权重、提高低波动行业的资金权重，使各行业承担的波动风险更接近。

## 资金参数（不计入≤5，可调整）

- 买入方式（buy_mode）：当前值 固定金额，范围 固定金额/固定比例；含义：选择每期按固定金额买入，还是按目标仓位比例买入。
- 每次买入金额（buy_amount）：当前值 5000，范围 0~10000000；含义：买入方式选固定金额时，每次最多计划投入多少钱。
- 每次买入比例（buy_ratio）：当前值 0.25，范围 0.01~1.0；含义：买入方式选固定比例时，每次最多补到目标仓位的多少比例。
- 买卖频率（rebalance_interval）：当前值 每月，范围 每日/每周/每两周/每月；含义：策略多久检查一次买卖信号并执行调仓。
- 初始资金（initial_capital）：当前值 1000000.0，范围 0~1000000；含义：回测开始时一次性准备的资金。
- 定期新增金额（extra_contribution_amount）：当前值 0.0，范围 0~100000；含义：按定期新增频率额外投入的资金；设为 0 表示回测期间不增加新资金。
- 定期新增频率（extra_contribution_freq）：当前值 每月，范围 每周/每月/每季/每年；含义：定期新增资金多久投入一次。
- 赎回比例（exit_ratio）：当前值 1.0，范围 0.1~1.0；含义：触发卖出时，卖出当前持有份额的多少比例；1 表示全部卖出。
- 回测区间（years）：当前值 4，范围 1~5；含义：用于统计回测结果的历史年数。
- 行业池（fund_pool）：当前值 银行、证券、保险、食品饮料、家电、农业、医药、煤炭、有色、钢铁、化工、汽车、军工、电子、计算机、通信、传媒、半导体、房地产、光伏、锂电、人工智能、国企改革，范围 银行/证券/保险/食品饮料/家电/农业/医药/煤炭/有色/钢铁/化工/汽车/机械/军工/电子/计算机/通信/传媒/半导体/电力/房地产/光伏/锂电/机器人/人工智能/国企改革；含义：参与轮动比较的行业集合。

## 参数修改示例

```bash
python scripts/params.py --config config/strategy.json --set "短期均线天数 30"
python scripts/params.py --config config/strategy.json --set "初始资金 800000"
python scripts/params.py --config config/strategy.json --set "每年新增 100000"
```
