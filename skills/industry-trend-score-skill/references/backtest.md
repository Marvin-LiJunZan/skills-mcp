# 回测

每次回测前检查本地缓存最新日期；若未覆盖最近一个已结束工作日，指标和指数从缓存最后日期之后增量补取并合并去重，基金净值按接口支持的区间刷新后合并；缓存新鲜时直接复用，不使用当天尚未收盘的数据。

本 skill 只回测一个已固化策略：同花顺行业基金趋势轮动策略。

## 命令

```bash
python scripts/run_backtests.py --config config/strategy.json --out-dir reports
python scripts/run_backtests.py --config config/strategy.json --out-dir reports/custom
```

## 指标集

- 通用底线：回测区间、基准（买入持有）对比、最大回撤。
- 策略指标：按实际投入节奏折算的年化收益率、一直持有基准的年化收益率、比一直持有多赚/少赚的百分点、期末资产、累计投入、累计盈利、平均现金占比、期末现金占比、申购周数、赎回周数、胜率、最长空仓天数。

## 指标解释

- **回测区间**：本次统计从哪一天开始、到哪一天结束。
- **一直持有基准**：行业轮动使用沪深300宽基指数买入持有作为基准；它用于判断策略是否跑赢一个宽基市场组合。
- **最大回撤**：历史上资产从阶段高点下跌到之后低点的最大跌幅，用来衡量最难受的一段亏损。
- **按实际投入节奏折算的年化收益率**：把每笔投入、取出和期末资产都纳入计算，更贴近分批买入、分批卖出的实际资金效率。
- **一直持有基准的年化收益率**：按相同时间和相同资金投入，只买入并持有基准时的年化收益率。
- **比一直持有多赚/少赚的百分点**：策略年化收益率与一直持有基准的差值；为正表示回测期内跑赢一直持有。
- **期末资产**：回测结束时，账户内基金市值与现金合计。
- **累计投入**：回测期内初始资金与后续定期新增资金的总和。
- **累计盈利**：期末资产减去累计投入。
- **平均/期末现金占比**：账户资金中没有买基金、停留在现金里的比例；占比越高，说明空仓或等待资金越多。
- **申购周数/赎回周数**：回测期内发生买入或卖出的周数。
- **胜率**：已完成买卖回合中，盈利回合占全部回合的比例。
- **最长空仓天数**：策略连续没有持有基金的最长自然日数。
- **夏普比率**：收益相对于净值波动大小的补偿水平；数值越高，表示单位波动对应的收益补偿越高。

## 结果解读

- 先输出通俗策略说明，再输出指标、收益曲线与买卖记录 CSV。
- 轮动图不标记买卖点，只保留策略收益曲线、基准、回撤和指标表。
- 优先看按实际投入节奏折算的年化收益率、最大回撤和比一直持有多赚/少赚的百分点。

## 展示要求

1. 必须说明这是历史回测、不构成收益承诺。
2. 给出通俗策略说明、回测区间、基准对比、最大回撤，以及上述策略指标。
3. 给出图路径与买卖记录 CSV 路径。

## 下一步按钮

回测输出后必须继续展示至少 2~4 个可点击按钮，例如：

- `view_latest_signal`｜查看最新信号
- `tune_parameters`｜调整策略参数
- `rerun_backtest`｜使用当前参数回测
- `explain_strategy`｜查看策略详细运行逻辑
- `setup_trade_plan`｜设置交易计划

按钮必须绑定明确 prompt，点击后直接执行，不得只提示“还可以继续”。
