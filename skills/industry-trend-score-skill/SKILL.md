# 同花顺行业基金趋势轮动策略

本 skill 只运行一个已固化的策略：同花顺行业基金趋势轮动策略。

面向用户的简要解释：策略每月比较各行业的近期平均走势、长期平均走势和最近一段时间的涨跌幅，选出中期趋势较强的行业；再根据行业波动大小分配资金，波动大的行业少投一些，波动小的行业多投一些。策略默认统计最近 4 年，调仓前会使用足够的历史数据计算长期均线。

## 策略理念与解释

以下策略说明以 `config/strategy.json` 的 `explanation` 为准，所有输出（回测、信号、调参）必须保持口径一致：

理念：趋势投资：选择中期走势更强且相对平稳的行业，趋势转弱时更换
规则：均线是过去若干个交易日净值的平均值。比较每个行业 30 日均线与 250 日均线：30 日均线越高，说明近期走势越强；再结合最近 20 个交易日涨跌幅。每月按综合强弱选择前两个行业；高波动行业少分配资金、低波动行业多分配资金，使各行业承担的波动风险更接近。本版本不参考大盘趋势过滤。前 1 年数据仅用于计算长期均线，默认展示最近 4 年结果。
仓位/费率：选中的两个行业按风险平价分配资金；高波动行业少分、低波动行业多分，使各行业承担的波动风险更接近。
可调整的策略参数：短期均线天数、长期均线天数、持有行业数、行业资金分配方式
资金相关设置：买入方式、每次买入金额、每次买入比例、买卖频率、初始资金、定期新增金额、定期新增频率、赎回比例、回测区间、行业池（均可调整）

## 用户术语说明

面向用户解释策略时，以下术语必须按这里的白话含义说明，不能只报术语：

- **均线**：过去若干个交易日净值的平均值，用来观察行业近期或中长期的平均走势。
- **均线趋势打分**：先比较每个行业短期均线和长期均线的相对强弱，再结合最近一段时间的累计涨跌幅，给行业做中期强弱排序。
- **持有行业数**：每月按综合强弱排序后，最多选择前几个行业持有。
- **行业资金分配方式=风险平价**：并非所有行业平均分配资金，而是让高波动行业少分一些、低波动行业多分一些，使各行业承担的波动风险更接近。

## 策略可调参数（≤5）

当前参数值与范围：

短期均线天数=30（5~120 天）；长期均线天数=250（60~500 天，必须大于短期均线）；持有行业数=2（1~5 个）；行业资金分配方式=风险平价（等权/排名加权/评分加权/风险平价）

## 资金参数（不计入≤5，可调整）

当前参数值与范围：

买入方式=固定金额(固定金额/固定比例)；每次买入金额=5000(0~10000000)；每次买入比例=0.25(0.01~1.0)；买卖频率=每月(每日/每周/每两周/每月)；初始资金=1000000.0(0~1000000)；定期新增金额=0.0(0~100000)；定期新增频率=每月(每周/每月/每季/每年)；赎回比例=1.0(0.1~1.0)；回测区间=4(1~5)；行业池=银行、证券、保险、食品饮料、家电、农业、医药、煤炭、有色、钢铁、化工、汽车、军工、电子、计算机、通信、传媒、半导体、房地产、光伏、锂电、人工智能、国企改革(银行/证券/保险/食品饮料/家电/农业/医药/煤炭/有色/钢铁/化工/汽车/机械/军工/电子/计算机/通信/传媒/半导体/电力/房地产/光伏/锂电/机器人/人工智能/国企改革)

这些资金参数不占用上述 ≤5 个策略参数名额；修改它们会改变累计投入、按实际投入节奏折算的年化收益率和现金占比。

### 3 定时与交易能力

- 定时可由交易 skill 的正式计划服务提供，或由宿主平台受支持的定时任务服务提供。策略 skill 负责编排，申购/赎回由交易 skill 承接。
- 定时任务负责每个交易日 14:30（Asia/Shanghai）使用前一交易日数据计算信号；产生申购或赎回建议后，先展示本次清单并等待用户确认发起。参数确认前明确展示“到期会请你确认是否发起本次交易，发起后每笔申购或赎回仍需确认才提交”。
- 截至 2026-09-08，本机交易 skill `thsfund` v0.2.2 声明持仓、单次申购、单次赎回、交易查询和撤单；其流程要求交易确认，未声明原生定时计划或无人值守交易。运行时以实际版本及平台能力为准。
- **到时先确认发起、逐笔提交确认**：平台按参数定时触发策略计算；若产生交易建议，先展示本次清单和“确认发起本次交易 / 跳过本次”按钮。用户点击确认后，才按清单逐笔进入交易 skill 的确认流程。交易 skill 展示每笔实际金额/份额并完成所需确认后才提交。用户未确认、拒绝或跳过时，本次不发起交易流程。
- 本版统一采用用户确认后才发起交易流程，不提供到时自动发起选项；进入交易 skill 后仍按其流程完成每笔订单确认，交易 skill 后续升级也不得自动改变已确认的计划执行方式。
- 若平台没有对应定时工具，或无法提供到期交互确认，保留已确认参数，说明具体缺口，状态记为“未创建”；与用户沟通后再继续。不得只输出计划文字就声称定时计划已设置。

### 4 创建、管理与到期执行

- 创建前查询是否已有相同用户和策略的统一计划；优先更新已有计划，防止重复扣款或重复赎回。
- 确认计划参数只代表授权创建统一定时计划；不替代到期的本次交易发起确认，也不替代交易 skill 要求的逐笔风险、协议、支付和最终确认。
- 到期先查询用户当前持仓，再展示本次全部建议标的、方向、实际金额或份额及原因，并提供“确认发起本次交易 / 跳过本次”原生按钮。用户确认发起后，才按清单逐笔进入交易 skill；确认超出本次有效交易时段、数据或订单要素发生变化时重新计算并确认，不沿用过期确认。
- 到期按钮固定使用：`confirm_due_trade`｜确认发起本次交易｜`我确认按本次展示的行业调仓清单发起交易`；`skip_due_trade`｜跳过本次｜`跳过本次行业调仓，不修改后续计划`。按钮点击后直接执行绑定动作。
- 某笔交易未确认、失败或被拒绝时单独记录，不能自动重试、替换标的或擅自提交该笔。跳过仅影响本次，暂停整个计划另用“暂停计划”。

- 记录统一计划标识、参数版本、执行方式、状态、时区和下次判断时间；计划内分别记录申购/赎回的本次执行结果。创建失败或结果不明时先查询，不盲目重复创建。
- 到期使用已确认参数快照和最新有效信号；未满足条件则记为跳过。数据缺失、授权失效或执行错误时按计划约定通知，不擅自修改标的、金额、份额或补单。
- 支持查看、调整、暂停和终止已创建的计划。调整后重新展示变动并取得确认，再更新原计划；不得留下旧计划继续执行。只能使用平台实际提供的管理能力，未提供的操作应说明限制。

## 编码与打包

- `SKILL.md`、`config/*.json`、`references/*.md` 与 `scripts/*.py` 必须保存为无 BOM 的 UTF-8；`SKILL.md` 的首字节必须直接是 `---`，避免影响 frontmatter 识别。
- 回测导出的 CSV 使用 UTF-8 with BOM（`utf-8-sig`），供 Windows、Excel 和前端工具直接打开；JSON 使用无 BOM 的 UTF-8。
- 若生成面向 Windows 用户下载的 Markdown 汇总文档，使用 UTF-8 with BOM，并在交付前确认不含 Unicode 替换字符 `U+FFFD`。
- Skill 包内文件名只使用 ASCII，避免 ZIP 工具对中文文件名采用不同编码；中文内容保留在文件正文中。
- 更新或打包前运行 `python scripts/check_encoding.py`；检查失败时不得发布或继续打包。
- 打包时排除运行时产物：`data_cache/`、`reports/`、`__pycache__/`；禁止包含 `.env`、`.env.example` 及其他 Key 配置文件。

## 基金推荐（按需触发）

只有用户明确提出“推荐基金”“选一只行业基金”等请求时才触发。本 skill 先结合同花顺行业基金趋势轮动策略的候选行业池、趋势评分、每月调仓频率、风险平价分配方式和预期持有周期，再结合用户已知的风险等级、持有期限、目标金额、费用敏感度、A/C 份额偏好、流动性需求和排除条件进行匹配；缺少会明显影响结果的信息时，只补问必要的 1~2 个问题，不擅自假定用户偏好。

- 仅使用同花顺金融数据API数据核验基金名称、代码、类型、跟踪行业/指数、A/C 份额、可申购状态、成立日期、净值完整性、风险等级、历史回撤、波动程度和费用；数据缺失时明确标注，不用未经核验的首选基金。
- 本策略按月轮动、可能较频繁调仓，默认优先比较 C 类；若用户计划长期持有或实际费用更适合 A 类，必须说明申购费、销售服务费和持有期差异，不能把 C 类规则当成绝对结论。
- 中低风险用户优先展示回撤和波动相对较小、风险等级不高于用户承受范围的候选；若策略本身与用户风险承受能力不匹配，直接说明不匹配，不通过换基金掩盖行业轮动风险。
- 一次给出 1~3 个按匹配度排序的候选，逐项展示：基金名称与代码、A/C 份额、跟踪行业或指数、风险等级、历史最大回撤、波动程度、申购/赎回/销售服务费、数据日期、推荐理由和主要风险。
- 推荐结果仅是“待确认标的”，不自动修改行业池、权重、回测基准、交易计划或发起申购/赎回。用户明确确认后，才可将所选基金带入重新回测或交易计划参数卡；交易仍按统一计划和逐笔确认流程执行。

推荐相关原生按钮：

- `recommend_funds`｜推荐匹配基金｜`请根据同花顺行业基金趋势轮动策略和我的偏好推荐匹配基金`
- `adjust_recommendation`｜调整推荐偏好｜`请展示当前基金推荐条件供我调整`
- `view_fund_details`｜查看基金详情｜`请展示选定基金的详情、费用和风险`
- `backtest_selected_fund`｜回测选定基金｜`请用选定基金按当前策略重新回测`

## 交易引导与边界

本 skill 只输出回测结果、买卖记录、当日信号、按需基金推荐与交易计划，不提供交易执行，不生成下单命令。

当用户明确要求实际交易（买入/卖出/申购/赎回/下单）时，先核对交易 skill 当前版本是否明确支持所需方式，再按以下口径引导，不主动推销：

> 如需实际买入/卖出，可以使用爱基金交易能力：
> - 买入：使用交易 skill 的基金申购能力
> - 卖出：使用交易 skill 的基金赎回能力
> - 查持仓：使用交易 skill 的持仓总览能力

禁止调用或复用交易类 skill 的任何接口；禁止输出下单步骤；禁止在交易 skill 未明确声明时声称支持自动交易。交易能力装配与鉴权引导见「前置条件与交易能力装配」节。

## 风险提示

历史回测结果基于历史数据与既定规则模拟，不代表未来收益；市场有风险，投资需谨慎。本 skill 输出仅为决策参考，不构成投资建议。
