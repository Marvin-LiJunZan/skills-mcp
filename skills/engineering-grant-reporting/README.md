## 🚀 如何使用本套件？

### 方式一：人类工程师与财务人员直接使用（无需任何 AI）
1. 打开 `templates/word/` 文件夹，根据项目当前阶段选择对应的 `.docx` 模板（如立项期选 `01`，中期选 `02`，结题期选 `04/05`），直接在 Word 中进行填报。
2. 打开 `templates/excel/` 文件夹，使用 `02_研发支出辅助账` 与 `03_研发人员工时分配表` 填报财务流水，表格内置自动求和与比例公式，防范低级算式错误。
3. 参考 `references/` 中的指南核对专利申请日期、剔除非研发费用（会费、认证费等）。

### 方式二：配合 AI 编码助手（Claude Code / Antigravity / Cursor / Codex）使用
只要将本文件夹复制到对应的技能或配置目录，AI 将自动具备“重大工程课题申报全流程审查与撰写”专精能力：

1. **Claude Code**：
   - 复制到当前项目根目录下的 `.claude/skills/engineering-grant-reporting`，或全局配置目录 `~/.claude/skills/`。
2. **Antigravity / Gemini CLI**：
   - 复制到 `~/.gemini/config/skills/engineering-grant-reporting` 或放入工作区 `skills/` 目录。
3. **对话直接调用指令示例**：
   - *“根据 `01_科技研发项目_立项申报书模板`，帮我撰写关于大跨度装配钢结构的立项方案”*
   - *“用 `audit_grant_consistency.py` 检查这份报告有没有 AI 味和心虚套话”*
   - *“按照十卷册核验指南，审查我们的 RD18 财务辅助账和人员工时台账”*

## ⚠️ 核心避坑指南（工程科技申报四大铁律）

1. **决议表“26”是得分，绝非26人**：历史计划汇总表中“26”为专家评审得分，切勿推断为研发人员数。人员必须按真实花名册与个税凭单填报。
2. **双版本口径统一**：股份公司申报版（3专题/460万）与集团正式批复版（6专题/1228万）存在口径差异时，统一以**最终正式批复的批件与合同**为准。
3. **彻底去除 AI 腔调**：禁止使用“显著提升”、“具有极其重大的历史意义”等空泛词，禁止在报告中写“本模型由于试验条件限制仅做初步探索”等防御性心虚措辞，一律以具体实测数据（公差、RMSE、检出率、试验样本量）说话。
4. **跨期与非研发费用必须剥离**：上年度奖金、常规工程资料承包款、协会会费、LEED认证咨询费等，严禁计入研发直接投入。
