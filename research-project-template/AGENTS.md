# AGENTS.md

1. Read `README.md` before making changes.
2. `paper/` contains the manuscript.
3. `src/` contains reusable source code.
4. `scripts/` contains experiment and plotting scripts.
5. Treat `data/raw/` as read-only.
6. Store processed data under `data/processed/`.
7. Store metrics, predictions and logs under `results/`.
8. Store publication-ready figures under `paper/figures/`.
9. Do not overwrite existing experimental results without explicit approval.
10. Before committing, summarize changed files and the effect of each change.
11. Run relevant tests or compilation before committing when possible.
12. Before reset, force push, branch deletion or file deletion, explain the impact and ask for confirmation.
13. Prefer small, meaningful commits.
14. Never commit credentials, API keys, private tokens or large raw datasets.
