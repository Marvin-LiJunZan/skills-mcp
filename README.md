# Skills & MCP Repository

This repository contains a comprehensive collection of AI agent skills, Model Context Protocol (MCP) servers, and related research tools.

## 📁 Repository Structure

- `skills/`: Collection of modular agent skills (e.g., Humanizer, Auto-Research-In-Sleep (ARIS), Deep Research, Academic Paper & Writing, Figure Generation, Patent Tools, PPT Masters, etc.)
- `mcp/`: Collection of Model Context Protocol (MCP) servers (e.g., Abaqus, Academic Search, ArXiv, Paper Search, Semantic Scholar, etc.)

## 🚀 Quick Start

### Skills
Refer to the individual `SKILL.md` files in each subfolder under `skills/` for specific usage instructions and dependencies.

### MCP Servers
Each MCP server under `mcp/` includes its corresponding implementation, environment setup, and tool configurations.
